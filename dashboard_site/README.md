# Fantasy Dashboard

FastAPI backend (+ a legacy static frontend, see below) for deterministic league stat queries. Does not modify the existing bot/GDoc code paths.

## Structure

- `dashboard_site/api`: FastAPI backend
  - `query_engine.py` / `app.py` `/query`, `/timeseries`, `/schedule_swap`, `/meta`: generic ad-hoc metric queries, reads `*_CompStats.csv` directly
  - `league_store.py` / `app.py` `/league/*`: Weighted-Rank-bearing views (weekly team card, weekly leaderboard, career/RS/PO totals & averages, all-time leaders, head-to-head, records/streaks) — built on `StatsStore`'s own CSV-loaded data plus `shared/weighted_rank.py` (dependency-free Weighted Rank math) and a precomputed playoff-bracket lookup (`Ref/real_matchup_flags.csv`, generated by `scripts/export_real_matchup_flags.py`). Does not import `Models`/`constants`.
- `dashboard_site/web`: legacy static HTML/JS frontend (no build step) — being replaced by a Next.js app per `_planning/web-app-build-plan.md`
- `dashboard_site/requirements.txt`: **incomplete as of the `/league/*` endpoints** — see note below

## Run locally

Runs on its own lightweight `.venv-dashboard` — no `Models`/`constants` import, so no `gspread`, `espn_fr`/`yfpy_fr`, or `scikit-learn` needed. Just `dashboard_site/requirements.txt`:

```bash
python3 -m venv .venv-dashboard   # first time only
.venv-dashboard/bin/pip install -r dashboard_site/requirements.txt
.venv-dashboard/bin/uvicorn dashboard_site.api.app:app --host 0.0.0.0 --port 8090 --reload
```

Open: `http://127.0.0.1:8090`

## Data source

By default it loads all `*_CompStats.csv` from:

- `$FANTASY_REF_DIR` if set
- else `<repo>/Ref` if that exists, else `<repo>/../Ref` (this is where the data actually lives locally), else `/srv/unisfantasy/data/ref` (prod)

## Current capabilities

- Deterministic metric aliasing (PTS/REB/AST/STL/BLK/TO/FG%/FT%/3PTM etc.)
- Derived deterministic metrics:
  - `wins`, `losses`, `draws`, `win%`
  - `category wins/losses/ties`
  - `all play wins/losses/ties`, `all play points`
  - `schedule luck` (actual matchup points - all-play avg points)
  - `draft score`, `draft picks`
- Generic filters: years/weeks/teams/opponents/RS-PO/count-only
- Generic aggregations: `sum`, `avg`, `min`, `max`, `count`, `rank`
- Grouping by one or more dimensions
- Trend endpoint for week/year charting
- Schedule swap endpoint:
  - `POST /schedule_swap` returns team-level actual vs all-play expected context
- Weighted-Rank-bearing views (`/league/*`, backed by `Models/League.py`):
  - `GET /league/meta` — years, members, current year/week, week counts, categories
  - `POST /league/weekly_team` — one team's stat line + Weighted Rank rating/rank for a given year/week
  - `POST /league/weekly_leaderboard` — full-league table for a given year/week, sorted by week rank
  - `POST /league/totals`, `POST /league/averages` — career/RS/PO aggregate totals or per-game averages with Weighted Rank
  - `POST /league/leaders` — all-time career-totals leader per category
  - `POST /league/head_to_head` — full matchup history + record between two members
  - `POST /league/records` — best week ever (overall + per category) and longest win streaks
